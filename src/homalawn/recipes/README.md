# Recipes

The recipes ship inside the `homalawn` package (`src/homalawn/recipes/`); `HOMALAWN_RECIPES` names another folder to read instead. Each `<name>.md` here is a written procedure an agent follows through the `homalawn mcp` tools (`recipe_list`, `recipe_get`) for a job inside another app. A file starts with frontmatter: `key: value` lines between `---` fences giving `name`, `title` (a short line a person reads, shown on the window's Agents page), `description` (one line), `needs` (comma-separated: apps, permissions, the user's taps) and `verified` (`yes` once the recipe was walked through on a phone or the test emulator, `no` while it is only the intended path; the window hides unverified recipes). Then the sections `## Goal`, `## Check first`, `## Steps` (tool calls, with what the screen should show after each), `## Verify` (a screenshot plus a `screen_tree` check that proves the result), `## If it goes wrong` and `## The user's part`. This README has no frontmatter, so it is not listed as a recipe.
